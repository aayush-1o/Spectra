## What Is SimSight?

SimSight is a **portfolio project** that simulates a large-scale data analytics platform — the kind used by intelligence analysis firms — built entirely on synthetic (fake) data generated by the computer itself.

It demonstrates these technical skills:
- Generating thousands of realistic-looking fake entities (people, locations, events)
- Storing and querying relationship graphs in Neo4j
- Detecting anomalous patterns using ML (Isolation Forest) and statistical rules (z-score)
- Building an interactive web dashboard with map views and graph visualisations
- Applying responsible data engineering practices with an ethics-first design

**Nothing in this project was sourced from real people.**

## Quick Start (Local Development)

### Prerequisites
- Docker Desktop
- Node.js 20+
- Python 3.11+ (optional — only needed to run scripts outside Docker)

### Run It

```bash
# 1. Clone
git clone https://github.com/<your-username>/simsight.git
cd simsight

# 2. Configure environment
cp .env.example .env

# 3. Start all backend services
docker compose up --build

# 4. Run database migrations (first run)
docker compose exec backend alembic upgrade head

# 5. Generate synthetic data (first run)
docker compose exec backend python -m app.data_gen.run --persons 500 --events 2000

# 6. Start the frontend
cd frontend && npm install && npm run dev
```

- **API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs
- **Frontend**: http://localhost:5173
